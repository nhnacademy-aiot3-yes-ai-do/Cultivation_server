## 문서 작성 규칙

- 이 문서들은 **코드가 진실**이라는 전제로 작성되었습니다. 코드와 다르면 코드가 맞습니다.
- 엔드포인트별 상세 요청·응답 스펙은 중복 관리를 피하기 위해 Swagger UI(`/swagger-ui.html`)에 둡니다.
  여기서는 "어떤 API가 있고 누가 호출할 수 있는지"까지만 다룹니다.
- 구조나 계약이 바뀌면 해당 문서도 같은 PR에서 함께 수정합니다.
